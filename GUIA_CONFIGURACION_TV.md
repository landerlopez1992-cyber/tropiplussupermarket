# 📺 Guía Profesional de Configuración de TVs

## 🎯 Casos de Uso Profesionales

### 1. **TV Entrada/Recepción** (Primera Impresión)
**Objetivo:** Dar la bienvenida y mostrar ofertas generales

**Configuración Recomendada:**
- **Nombre:** `TV Entrada` o `TV Recepción`
- **Modo:** `Mixto (Productos + Promo)`
- **Categoría:** `Todas las categorías`
- **Cantidad de productos:** `12-15` (variedad amplia)
- **Segundos por producto:** `8-10` segundos
- **Mostrar precio:** ✓ Sí
- **Mostrar etiqueta OFERTA:** ✓ Sí
- **Texto promocional:** 
  ```
  Bienvenido a TropiParts - Ofertas del día - Productos frescos y de calidad
  ```
- **TV activo:** ✓ Sí

**Por qué esta configuración:**
- Muestra variedad para atraer diferentes intereses
- Tiempo suficiente para que los clientes vean varios productos
- Texto de bienvenida crea ambiente acogedor

---

### 2. **TV Pasillo/Categoría Específica** (Productos por Sección)
**Objetivo:** Mostrar productos de una categoría específica donde está ubicado el TV

**Configuración Recomendada:**
- **Nombre:** `TV Pasillo Carnes` o `TV Sección Lacteos`
- **Modo:** `Solo Productos`
- **Categoría:** Seleccionar la categoría específica (ej: `Carnes`, `Lacteos`, `Frutas`)
- **Cantidad de productos:** `6-8` (enfoque en la sección)
- **Segundos por producto:** `12-15` segundos (más tiempo para leer detalles)
- **Mostrar precio:** ✓ Sí
- **Mostrar etiqueta OFERTA:** ✓ Sí
- **Texto promocional:** 
  ```
  (Dejar vacío) o "Carnes frescas todos los días" / "Lacteos de calidad premium"
  ```
- **TV activo:** ✓ Sí

**Por qué esta configuración:**
- Enfoque en productos relevantes a la ubicación
- Más tiempo permite ver detalles del producto
- Menos productos evita saturación visual

---

### 3. **TV Caja/Pago** (Impulso de Última Compra)
**Objetivo:** Mostrar ofertas rápidas mientras el cliente espera o paga

**Configuración Recomendada:**
- **Nombre:** `TV Caja 1`, `TV Caja 2`, etc.
- **Modo:** `Mixto (Productos + Promo)`
- **Categoría:** `Todas las categorías` o categorías con ofertas destacadas
- **Cantidad de productos:** `10` productos
- **Segundos por producto:** `6-8` segundos (más dinámico)
- **Mostrar precio:** ✓ Sí
- **Mostrar etiqueta OFERTA:** ✓ Sí (muy importante aquí)
- **Texto promocional:** 
  ```
  Aprovecha nuestras ofertas especiales - ¡No te pierdas estas promociones!
  ```
- **TV activo:** ✓ Sí

**Por qué esta configuración:**
- Rotación rápida mantiene la atención
- Ofertas visibles pueden generar compras de último minuto
- Texto promocional refuerza el mensaje de ofertas

---

### 4. **TV Solo Promoción** (Anuncios y Eventos)
**Objetivo:** Mostrar solo mensajes promocionales, eventos o información general

**Configuración Recomendada:**
- **Nombre:** `TV Promociones` o `TV Anuncios`
- **Modo:** `Solo Promoción`
- **Categoría:** (No aplica)
- **Cantidad de productos:** (No aplica)
- **Segundos por producto:** (No aplica)
- **Texto promocional:** 
  ```
  ¡Gran Evento! Este fin de semana 20% de descuento en toda la tienda - 
  Válido hasta el domingo - No te lo pierdas - Visita nuestra sección de ofertas
  ```
- **TV activo:** ✓ Sí

**Por qué esta configuración:**
- Ideal para anunciar eventos especiales
- Información importante sin distracciones
- Mensajes largos y detallados

---

### 5. **TV Ofertas Destacadas** (Productos en Rebaja)
**Objetivo:** Mostrar solo productos con descuentos o ofertas especiales

**Configuración Recomendada:**
- **Nombre:** `TV Ofertas` o `TV Rebajas`
- **Modo:** `Solo Productos`
- **Categoría:** `Todas las categorías` (el sistema filtrará automáticamente ofertas)
- **Cantidad de productos:** `8-10`
- **Segundos por producto:** `10` segundos
- **Mostrar precio:** ✓ Sí (muy importante)
- **Mostrar etiqueta OFERTA:** ✓ Sí (esencial)
- **Texto promocional:** 
  ```
  Ofertas especiales del día - Ahorra más en Tropiplus
  ```
- **TV activo:** ✓ Sí

## ⚙️ Explicación de Cada Opción

### **Modo de Contenido**

1. **Mixto (Productos + Promo)**
   - Muestra productos rotando + texto promocional en la parte inferior
   - **Ideal para:** Entrada, cajas, áreas generales
   - **Ventaja:** Combina información de productos con mensajes promocionales

2. **Solo Productos**
   - Solo muestra productos rotando, sin texto promocional
   - **Ideal para:** Pasillos, secciones específicas
   - **Ventaja:** Enfoque total en productos, menos distracciones

3. **Solo Promoción**
   - Solo muestra texto promocional (sin productos)
   - **Ideal para:** Anuncios de eventos, información general
   - **Ventaja:** Mensaje claro y directo

---

### **Categoría de Productos**

- **Todas las categorías:** Muestra productos de cualquier categoría
- **Categoría específica:** Solo muestra productos de esa categoría
  - Útil para TVs en pasillos específicos (ej: TV en pasillo de carnes muestra solo carnes)

---

### **Cantidad de Productos a Rotar**

- **Rango:** 1-50 productos
- **Recomendaciones:**
  - **6-8:** Para categorías específicas (enfoque)
  - **10-12:** Para áreas generales (balance)
  - **15+:** Para entrada (máxima variedad)

**Nota:** Más productos = más variedad, pero cada producto aparece menos frecuentemente

---

### **Segundos por Producto**

- **Rango:** 3-60 segundos
- **Recomendaciones:**
  - **6-8 segundos:** Áreas de tránsito rápido (cajas)
  - **10-12 segundos:** Áreas generales (entrada, pasillos)
  - **15+ segundos:** Productos con mucha información o texto

**Nota:** Más tiempo = más oportunidad de leer, pero rotación más lenta

---

### **Mostrar Precio en Pantalla**

- **✓ Sí:** Muestra el precio del producto
  - **Ideal para:** Todas las situaciones (los clientes quieren ver precios)
- **✗ No:** No muestra precio
  - **Ideal para:** Solo si quieres crear curiosidad o el precio está en otro lugar

---

### **Mostrar Etiqueta OFERTA**

- **✓ Sí:** Muestra badge "OFERTA" en productos con descuento
  - **Ideal para:** Cajas, entrada, áreas de ofertas
- **✗ No:** No muestra badge
  - **Ideal para:** Presentación más limpia, menos "ruido" visual

---

### **Texto Promocional para este TV**

- **Vacío:** Usa la promoción global configurada en la pestaña "Promocion"
- **Con texto:** Muestra este texto específico solo en este TV
  - **Ideal para:** Mensajes personalizados por ubicación
  - **Ejemplo:** TV en pasillo de carnes: "Carnes frescas todos los días"

---

### **TV Activo**

- **✓ Sí:** El TV está activo y mostrará contenido
- **✗ No:** El TV está desactivado (útil para mantenimiento o temporadas)

---

## 🎬 Flujo de Trabajo Profesional

### Paso 1: Crear el TV
1. Ve a **Admin → TV**
2. Completa el formulario con la configuración recomendada según el tipo de TV
3. Haz clic en **"Guardar TV"**

### Paso 2: Obtener el ID del TV
1. En la lista de "TVs Registrados", verás el TV que acabas de crear
2. Haz clic en **"Abrir Pantalla TV"** para ver la URL
3. O copia el ID del TV de la URL: `tv.html?tv=ID_DEL_TV`

### Paso 3: Configurar el TV Físico
1. Abre el navegador en el TV/Box (Chrome, Android TV, etc.)
2. Navega a: `http://TU_SERVIDOR/tv.html?tv=ID_DEL_TV`
3. Presiona **F11** (o botón de pantalla completa) para modo kiosko
4. El TV comenzará a mostrar el contenido automáticamente

### Paso 4: Mantenimiento
- **Editar:** Haz clic en "Editar" en la lista de TVs para cambiar configuración
- **Desactivar:** Desmarca "TV activo" para pausar sin eliminar
- **Eliminar:** Haz clic en "Eliminar" para borrar permanentemente

## 💡 Tips Profesionales

1. **Nombres descriptivos:** Usa nombres claros como "TV Entrada", "TV Caja 1", no "TV1", "TV2"

2. **Consistencia:** Mantén tiempos similares entre TVs en la misma área para experiencia uniforme

3. **Actualización automática:** El sistema actualiza productos cada 5 minutos automáticamente

4. **Prueba antes de instalar:** Abre la URL en tu computadora primero para verificar que se ve bien

5. **Backup de configuración:** Los TVs se guardan en `localStorage`, considera hacer backup periódico

6. **Modo kiosko:** En Chrome, usa `--kiosk` flag para iniciar automáticamente en pantalla completa

---

## 🔧 Solución de Problemas

**El TV no muestra productos:**
- Verifica que el TV esté marcado como "Activo"
- Verifica que haya productos en la categoría seleccionada
- Revisa la consola del navegador (F12) para errores

**El texto promocional no aparece:**
- Si dejaste el campo vacío, verifica que haya una promoción global configurada
- Si pusiste texto, verifica que el modo no sea "Solo Productos"

**Los productos no rotan:**
- Verifica que "Cantidad de productos" sea mayor a 0
- Verifica que "Segundos por producto" esté entre 3-60
